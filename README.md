Personal Expense Tracker

A simple and user-friendly web application that helps users record daily expenses, manage spending, and understand their financial habits.

Project Overview

The Personal Expense Tracker is a web-based application designed to make expense management easier. Users can record their daily spending, organize expenses into categories, and view monthly spending totals.

Features

- Add new expenses
- Edit and delete expenses
- Categorize expenses (Food, Transport, Shopping, etc.)
- View total expenses
- Calculate monthly spending
- Display expenses using bar charts
- Search and manage expense records

Technologies Used

- HTML5 – Website structure
- CSS3 – Website design and styling
- JavaScript – Application functionality
- SQL – Database management


 Project Goal

The goal of this project is to develop a simple expense management system that helps users track their spending, organize financial records, and manage their money more effectively.

Future Improvements

- Add user login and registration
- Add monthly budget settings
- Improve chart visualization
- Add expense reports
- Make the application mobile-friendly
