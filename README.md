# 💰 Personal Expense Tracker

A simple web application to record daily expenses and manage monthly spending.

## 🌐 Live Demo

👉 [Visit My Personal Expense Tracker Website](https://a25ha025-ctrl.github.io/Personal-Expense-Tracker/)

## ✨ Features

- Add, edit, and delete expenses
- Categorize expenses
- Calculate monthly spending
- Display expenses using bar charts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- SQL
